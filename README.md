# Dhyuthi-6.0_Songwriting_Studio

Songwriting Studio was developed for the AIGENIX competition at Dhyuthi 6.0, where the challenge was to come up with an innovative idea and build a solution using AI Agents. I was able to secure first place in this competition.

# Overview

Songwriting Studio is an AI-powered multi-agent system designed to generate and refine original songs based on user-selected inputs such as theme, emotion, and genre.

The system uses multiple specialized AI agents that collaborate to create lyrics, analyze their emotional flow, improve their quality, suggest musical elements, and finally evaluate the completed song.

# Features

The user provides three main inputs:

Theme – The central idea or subject of the song

Emotion – The feeling the song should express and the intensity of that feeling

Genre – The musical style of the song

# Based on these inputs, Songwriting Studio produces:

Original song lyrics

Verse, chorus, and bridge structure

Emotion-based lyric adaptation

Improved rhyme, rhythm, and imagery

Chord progression suggestions

Recommended BPM

Final song critique

Catchiness and lyric rating out of 10
